Datenschutz

LycheeLab ist ein Studienprojekt und kann ohne Registrierung oder Benutzerkonto verwendet werden.

Hosting

Die Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website wird eine Verbindung zu den Servern von GitHub hergestellt. Nach Angaben von GitHub wird dabei unter anderem die IP-Adresse der Besuchenden zu Sicherheitszwecken protokolliert.

Lokale Speicherung

LycheeLab speichert Spieleinstellungen und Spielstatistiken lokal im Browser des verwendeten Geräts. Diese Daten werden von LycheeLab nicht an einen eigenen Server übertragen.

Zu den lokal gespeicherten Informationen können beispielsweise der gewählte Schwierigkeitsgrad sowie Statistiken zu Minesweeper und 2048 gehören.
